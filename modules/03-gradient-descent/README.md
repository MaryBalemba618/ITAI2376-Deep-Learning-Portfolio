# Gradient descent for a younger audience

Mary Balemba

Assignment: A04

## My reflection

I used a foggy mountain to explain gradient descent to an 11-year-old. The height represents loss, and each downhill step represents a weight update. Explaining the learning rate helped me understand why large steps can miss a useful solution and small steps can take longer. I also learned that an analogy has limits because real networks adjust many parameters at once.
