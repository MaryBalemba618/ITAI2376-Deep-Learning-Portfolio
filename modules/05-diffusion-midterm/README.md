## My reflection

The diffusion notebook helped me connect the training loop with actual outputs. I used a class-conditioned U-Net to predict noise in Fashion-MNIST images. My saved run contains 30 epochs. I learned to check the validation loss alongside the generated samples because a lower noise error does not guarantee a clear image. Fixing missing imports and using the GPU also showed me why execution order and runtime settings matter.
