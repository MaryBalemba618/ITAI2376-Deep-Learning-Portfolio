# Articles videos and technical resources

I kept the resources linked to the work where I used them. These short notes explain why each source matters to my learning.

| Resource | Connection to my portfolio |
| --- | --- |
| [TensorFlow beginner quickstart](https://www.tensorflow.org/tutorials/quickstart/beginner) | The Keras example helped me compare the steps for creating and evaluating a neural network in A02b. |

| [Villeneuve, 2016: Arrival](https://www.paramountpictures.com/movies/arrival) | The film is the media source for A05. I discuss scenes in my own words and keep fictional events separate from technical claims. |
| [Python tutorial](https://docs.python.org/3/tutorial/), [AST](https://docs.python.org/3/library/ast.html), [SQLite](https://docs.python.org/3/library/sqlite3.html) | These references support LearnPath's beginner topics, restricted expression checking and Colab progress storage. |
| [Slivkins, 2019: Introduction to Multi-Armed Bandits](https://arxiv.org/abs/1904.07272) | This reference supports the feedback-based style selection in LearnPath. |

Sources checked November 25, 2026. The original submissions also retain their own reference lists. Short resource descriptions are new portfolio reflections, not copied article passages.
